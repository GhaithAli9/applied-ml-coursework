# Exercise 7 — Decision Trees from Scratch

## Overview

A classification decision tree implemented from scratch and evaluated on the Iris dataset. The result is cross-checked against scikit-learn's `DecisionTreeClassifier`.

## Techniques used

- Impurity measures: **Gini index** and **cross-entropy**
- Greedy best-split search and recursive tree building
- Class-probability prediction and accuracy evaluation
- Printing the tree level by level with breadth-first search
- Counting nodes and leaves, and analysing individual nodes
- Post-pruning that walks internal nodes in post-order

# Exercise 5 — Mini-Batch Gradient Descent, Cross-Validation and Newton's Method

## Overview

Regularized linear and logistic regression with hyperparameters chosen by k-fold cross-validation, all implemented from scratch. Regression uses the Wine Quality dataset and classification uses Bank Marketing.

## Techniques used

- Mini-batch gradient descent for regression and logistic regression
- k-fold cross-validation and grid search over learning rate and regularization strength
- L2-regularized logistic regression trained with **Newton's method** (gradient and Hessian)
- Comparison with scikit-learn `Ridge`, `LogisticRegression` and `GridSearchCV`

# Exercise 6 — Regularization, Polynomial Features and Elastic Net

## Overview

Regularized linear models on the red Wine Quality dataset: comparing generalized linear models, studying how polynomial degree and ridge regularization affect fit, and implementing Elastic Net trained with SGD.

## Techniques used

- Outlier inspection with boxplots
- Linear, Ridge and Lasso regression with grid-search cross-validation (scikit-learn pipelines)
- Polynomial feature expansion at different degrees and its effect on over-/underfitting
- Ridge regularization strength analysis
- Elastic Net implemented with stochastic gradient descent, with a cross-validation heatmap over its hyperparameters
